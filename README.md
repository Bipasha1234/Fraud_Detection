Title: Fraud Detection System – Mobile Banking

Description:
Developed a fraud detection system for mobile banking using predictive and prescriptive analytics. Historical login and transaction patterns were analyzed with machine learning models to identify suspicious activities. Real-time monitoring and interactive dashboards were implemented for decision-making.

Technologies / Tools Used:
- Python, FastAPI, Streamlit, Tableau
- Machine learning models for prediction and prescriptive analytics
- MongoDB

Key Functionalities:
- Fraud detection using ML models
- Real-time monitoring with FastAPI
- Interactive dashboards for actionable insights
- Batch predictions and alert system

Learnings:
- Developed predictive and prescriptive analytics workflow
- Integrated dashboards for clear visualization
- Strengthened understanding of ML model deployment
